# Legal review notes (for the owner)

Plain-language list of what a reviewer should check before this site goes public. This is not legal advice and nothing here makes the project "lawsuit-proof"; it records what was done and what still needs a human decision.

## 1. Roblox: trademark and affiliation
- The site uses the word "Roblox" only descriptively (what the extension works with). No Roblox logos, fonts, screenshots, avatars or assets are used.
- Every page footer says: "not affiliated with, endorsed, sponsored or approved by Roblox Corporation. Roblox is a trademark of Roblox Corporation." The terms page repeats it.
- The name "RoFit" combines "Ro" + "Fit". Roblox's brand guidelines have historically discouraged names that start with "Ro"/"Robl". **Decision needed:** confirm the owner is comfortable with the name, or check Roblox's current brand/usage guidelines.
- The demo's stand-in profile page is deliberately generic (own layout, own fonts, labelled "a stand-in for a Roblox profile page · sample data") so it isn't mistaken for roblox.com.

## 2. Sample art and data
- Figures and items are original flat SVG drawings generated by `src/demo/art.ts`. They are blocky figures, which is a generic style, but they are evocative of Roblox avatars. **Check:** acceptable resemblance.
- All names, creators ("Sample Studio/Atelier/Workshop"), users ("Sample Wardrobe", "Hidden Closet", "Fresh Account") and prices are invented and labelled as sample data. IDs are in ranges (800000000000xxx, 900000000000xxx, 910000000000xxx) chosen not to point at real Roblox content.
- Item states in the hero are labelled "illustrated states".

## 3. Roblox Terms of Use and APIs
- RoFit reads Roblox's public web APIs from the user's own browser, as roblox.com itself does, with the user's own session, read-only, rate-limited, and honouring Roblox's outfit-privacy refusals. It doesn't scrape at scale, store data off-device or work around privacy.
- Automated access is a grey area under most platform terms. **Check:** Roblox's current Terms of Use regarding third-party tools/extensions. The site doesn't claim Roblox approves of RoFit.
- **No live lookup is offered on the website.** Roblox's APIs send no CORS headers, so a static site can't call them; doing it would need a proxy server that makes requests on behalf of visitors. That raises ToS, rate-limit and data-handling questions, so it was deliberately not built. If wanted later: an anonymous, allow-listed, cached, rate-limited proxy that never takes cookies and refuses private outfits, plus a privacy-policy update. Needs owner approval.

## 4. Privacy claims (scope)
- Claims are limited to what the code does (verified against `src/`, `public/manifest.json`, README): no analytics, no server, storage in `chrome.storage.local` + IndexedDB `rofit`, six read-only API hosts, requests relayed via an open roblox.com tab, thumbnails pruned after 7 days, snapshot limit setting, Settings → clear/export.
- The permission table on the home page is generated from the manifest at build time, and `build.mjs` refuses to build if a new permission appears without an explanation (`home.ts`).
- The website itself: no cookies/storage/analytics/third-party requests (meta CSP enforces same-origin). The **hosting provider** may log IPs; the policy says so generically. **Decision needed:** once a host is chosen, name it in the privacy policy.
- Children: many Roblox users are minors. RoFit collects nothing, which is the simplest position under COPPA/GDPR-K. A reviewer should still confirm no jurisdiction-specific notice is needed.
- No contact email is published; contact is GitHub issues. **Decision needed:** add an email if the owner wants one (some jurisdictions expect a contact address for privacy questions).

## 5. Security reporting
- GitHub private vulnerability reporting is currently **disabled** on the repo (checked via the API). The security page links to it and gives a fallback (public issue with no details). **Recommended:** enable it in repo Settings → Security.

## 6. Distribution
- Installation is "Load unpacked" from a zip in the repo (not the Chrome Web Store). The site explains this plainly, shows file size + SHA-256 computed at build, and says updates are manual. It makes no claim of store review.
- The terms page defers to the MIT License for warranty/liability.

## 8. Things deliberately not claimed
No user counts, ratings, testimonials, "safe"/"approved" badges, store links, price history, outfit dates, or real Roblox prices.
